## 3. Suggested Improvements

The following improvements are proposed for future project stages. They are recommendations, not claims that the features have already been implemented.

1. **Requirements Validation:** Validate the documented requirements against the selected base application and refine any missing or unsupported features.
2. **Performance Testing:** Define a repeatable test workload and measure response times before setting final performance targets.
3. **Deployment Reliability:** Validate the CI/CD pipeline and document recovery or rollback procedures.
4. **Security:** Run code-quality and container vulnerability scans, review findings, and address critical issues before release.
5. **Monitoring and Logging:** Configure dashboards and centralized logs for the core services, then verify that the collected data is useful for troubleshooting.
6. **Infrastructure Cost Management:** Review cloud resource usage and configure budgets or alerts where available.
7. **Documentation:** Keep architecture diagrams, deployment instructions, testing evidence, and operational procedures up to date.
8. **Backup and Recovery:** Define and test an appropriate backup and restoration procedure for persistent application data.
